# Roadmap

## v1.0 — Foundation
- [x] Project scaffold + docs
- [ ] Breath-hold timer with state machine
- [ ] Guided breathe-up (configurable rounds)
- [ ] Session history with SwiftData
- [ ] Stats screen with Swift Charts
- [ ] Calm/zen UI with breathing orb
- [ ] Accessibility: VoiceOver, Dynamic Type, Reduce Motion

## v1.1 — Polish
- [ ] App icon + launch animation
- [ ] Haptic and sound refinements
- [ ] Onboarding (3 screens)
- [ ] Custom breathe-up presets

## v1.2 — Health
- [ ] HealthKit integration (write breath-hold to mindful minutes)
- [ ] Resting HR tracking before/after a hold (Apple Watch)

## v1.3 — Sync
- [ ] iCloud sync for session history (CloudKit-backed SwiftData)
- [ ] Export sessions as CSV

## v2.0 — Watch + Beyond
- [ ] watchOS companion app
- [ ] Widgets (last hold, personal best)
- [ ] Live Activity during a hold
- [ ] Localization (Spanish, French, Japanese, Chinese)

## Non-goals
- Account systems
- Social features (leaderboards, sharing feeds)
- Ads or analytics
